# Changelog

## 0.1.0 — 2026-11-08

Initial usable source release on GitHub; not published to Mooncakes.

* Strict validated declarations, canonical JSON and stable-v1 compatibility gates.
* OpenMetrics observations through moonopenmetrics 0.1.1; supported-profile
  validation rejects unsupported data rather than returning partial passes.
* Multi-source verification, conservative drafting, descriptor-only records and
  replay, source-specific requirements and a file-based coverage-plan gate.
* Consistent declaration composition, explicit scope selection and exact schema diffs.
* Exact-model-bound migration decisions preserving incompatible and unknown evidence.
* Attributed Kubernetes descriptor fixtures, synthetic integration cases, executable
  examples and three-system, four-target CI with actual native CLI execution.

Supported profiles and resource limits are documented. This release does not
authenticate source/reviewer identities, prove unseen runtime behavior, or claim
production adoption, ecosystem exclusivity or performance advantages.
